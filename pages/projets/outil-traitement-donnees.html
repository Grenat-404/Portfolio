Outil de traitement de données

Outil Python doté d’une interface PyQt5 pour détecter, visualiser et supprimer de manière sécurisée les fichiers volumineux.

01 — Contexte

Analyser les fichiers volumineux d’un ordinateur

Le projet consiste à créer un outil d’analyse de répertoires capable de filtrer les fichiers selon leur taille, de présenter les résultats dans une interface graphique et de sécuriser leur suppression.

02 — Objectifs

Ce que le projet devait accomplir

  • Analyser récursivement un répertoire avec Python et Pathlib.
  • Présenter les résultats dans une interface PyQt5.
  • Afficher des graphiques dynamiques avec PyQtChart.
  • Automatiser le lancement et la suppression avec PowerShell.
  • Conserver une approche portable grâce à l’échange de métadonnées en JSON.

03 — Démarche

Les principales étapes

01

Analyse

Développement d’un script de parcours de répertoires et de filtrage selon la taille.

02

Interface

Création d’une interface graphique interactive avec PyQt5.

03

Visualisation

Ajout de graphiques dynamiques présentant les fichiers détectés.

04

Sécurisation

Création de scripts PowerShell avec confirmation avant suppression.

Technologies et outils

  • Python
  • Pathlib
  • PyQt5
  • PyQtChart
  • PowerShell
  • JSON

04 — Résultats

Ce qui a été réalisé

  • Outil complet d’analyse de fichiers volumineux.
  • Interface graphique fonctionnelle avec graphiques dynamiques.
  • Suppression sécurisée à l’aide de PowerShell.

05 — Bilan

Compétences développées

Renforcement des compétences en Python, PyQt5 et PowerShell.

Compréhension de l’importance de la modularité, de l’ergonomie et de la portabilité multi-OS.
