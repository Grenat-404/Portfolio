Gestionnaire de trafic aérien

Application Django permettant de gérer les aéroports, les pistes, les compagnies, les avions et les vols.

01 — Contexte

Gérer les données et les règles d’un trafic aérien

Développement d’une interface de gestion du trafic aérien entre aéroports. Le gestionnaire peut créer et administrer les aéroports, les pistes d’atterrissage, les compagnies, les types d’avion, les avions et les vols.

02 — Objectifs

Ce que le projet devait accomplir

  • Concevoir un modèle de données couvrant l’ensemble des entités du trafic aérien.
  • Développer une interface CRUD avec des validations métier.
  • Gérer la disponibilité des pistes avec un créneau de dix minutes par vol.
  • Permettre l’import de vols par fichier CSV.
  • Générer des fiches de vols selon un aéroport et une période.

03 — Démarche

Les principales étapes

01

Modélisation

Conception du schéma relationnel pour les aéroports, pistes, compagnies, types d’avion, avions et vols.

02

Infrastructure

Déploiement de deux machines virtuelles : MariaDB d’un côté, Django avec Nginx et Gunicorn de l’autre.

03

Développement

Création des vues, formulaires et opérations CRUD avec contrôle des champs et de la longueur des pistes.

04

Validation

Ajout de la réservation des pistes, de l’import CSV, des fiches de vols et réalisation de tests.

Technologies et outils

  • Django
  • Python
  • HTML & CSS
  • MariaDB
  • Nginx
  • Gunicorn

04 — Résultats

Ce qui a été réalisé

  • Modèle de données complet pour les vols, avions, aéroports et pistes.
  • Interface CRUD fonctionnelle.
  • Système de réservation de pistes tenant compte des créneaux occupés.
  • Import de configurations et de vols.
  • Fiches de vols générées dynamiquement.

05 — Bilan

Compétences développées

Maîtrise renforcée de Django, de la conception de modèles de données complexes et de l’implémentation de règles métier.

Travail collaboratif réparti entre le développement CRUD, la base de données et la configuration des machines virtuelles.
